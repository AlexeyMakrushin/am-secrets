# Реализация

- Ошибка настройки воспроизведена с реальным тестовым демоном. В исходной версии ответ по умолчанию записывает в `.zshrc` вызов автоматической обёртки. Проверка локального lock также выявила лишнюю команду `bw sync`.
- Setup проверяет выбранный профиль и пароль до записи нового хранилища. Успешная настройка предлагает только PATH. Неудачная проверка пароля сохраняет возможность повтора.
- Блокировка локального сеанса пропускает сетевую синхронизацию. Другие команды сохраняют правила синхронизации.
- Удалена неиспользуемая зависимость anyhow. Rand обновлён до исправленной версии 0.8.6. RustSec сообщает одно предупреждение о прекращении поддержки транзитивного YAML-парсера, известных уязвимостей по базе прогона нет.
- Подготовлены MIT, инструкция, проверка явной shell-функции через подстановку CLI. Состав кандидата ограничен нужными исходниками и документацией.
- Независимая проверка выявила два дефекта установщика. Сохранение симлинка и отказ при незакрытом блоке подтверждены регрессионными тестами. Тесты фиксируют собственные пути и сокет.
- Справка CLI предупреждает о поведении устаревшей команды. README объясняет явное подключение профиля Bitwarden, отдельный профиль при неизвестном адресе и типовые вызовы `wrap`.
- Итоговая версия 3.4.1, исходники для macOS. Решение о переключении видимости остаётся за владельцем.
