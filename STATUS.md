# Состояние am-secrets

Обновлено 22.11.2026, Москва.

Цель — подготовить новую версию am-secrets для macOS к публикации. Границы — в [спецификации](.scratch/publication/spec.md).

## Что уже работает

От версии 3.4.0 сохранены шифрованное локальное хранилище, сеанс в памяти демона, выдача полей по полным путям, ручная и фоновая синхронизация. Базовые тесты прошли на macOS arm64: Rust 25, Swift 9, установщик 2.
