# Метки задач

- `needs-triage` — нужна первичная оценка.
- `needs-info` — нужно уточнение.
- `ready-for-agent` — задача готова к выполнению агентом.
- `ready-for-human` — нужно действие человека.
- `wontfix` — задача закрыта решением не выполнять её.

Поле Execution отражает ход исполнения независимо от метки.
