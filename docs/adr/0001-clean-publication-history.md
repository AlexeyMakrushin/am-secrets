# 0001. Новая история по прежнему адресу

Статус — принято 22.11.2026.

Изменение текущих файлов сохраняет прежние объекты Git. Переписывание коммитов также не гарантирует исчезновения ссылок закрытых PR на сервере. Существующую историю сохраняем в приватном архиве. По прежнему адресу будет отдельный проект с новым корневым коммитом, лицензией MIT и текущими исходниками. Новый проект остаётся приватным до решения владельца.

Цена решения — старые клоны и ссылки на коммиты относятся к архиву. Старый и новый проекты нужно различать при настройке Git remote.
