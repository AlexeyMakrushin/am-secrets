# secrets-cli — CLI проекта am-secrets

Сборка: `cargo build --release`. Исполняемый файл — `secrets`.

Команды, установка и ограничения описаны в [основном README](../README.md), [справке команд](../docs/COMMANDS.md) и [архитектуре](../docs/ARCHITECTURE.md). CLI 3.3 требует daemon с протоколом 2; `../install.sh` обновляет оба компонента; CLI-only обновление при неизменном протоколе возможно без рестарта демона.

Тесты: `cargo test --offline`. Сквозные сценарии — `../tests/`; реальные секреты в тестах не используются.
