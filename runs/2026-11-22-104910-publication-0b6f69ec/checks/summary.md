# Проверка am-secrets 3.4.1

Тег — `v3.4.1`. Исходный коммит — `7481b2986ee03d6245194cbe3a2e63c79474ad25`. Лицензия MIT. Проверено 22.11.2026.

## Реализация

- Сохранили шифрование локальных данных, сеанс в памяти подписанного Swift-демона, штатную проверку полного пути и явный выбор полей. Синтетические тесты проверяют перенос, ограничения выдачи, работу после блокировки, защиту при сбоях синхронизации и миграцию старого формата.
- До исправления первичная настройка добавляла устаревший автоматический запуск в zsh и могла оставить недоступное хранилище после неверного пароля. Теперь она проверяет провайдера до записи, а интеграция оболочки добавляет только PATH. Установщик сохраняет символическую ссылку и строки вне своего блока. Повреждённый блок остаётся без изменений.
- Блокировка выполняется без предварительного `bw sync`. Другие команды сохранили обычные правила синхронизации. Пакет `rand` обновлён до 0.8.6, неиспользуемый `anyhow` удалён.
- Отдельного shell-файла для выдачи полей нет. Команда `secrets wrap` входит в CLI, пример именованной функции для zsh находится в README.

SHA-256 ZIP — `6b4a919815c86143b4775f836b4256072e08d84f6e002818b061d3808b6da4e2`.

Живой Bitwarden, интерактивная 2FA, запуск установщика через рабочий launchd и Intel в этом прогоне не проверялись. При внезапном завершении процесса во время записи setup возможен незавершённый комплект файлов. Это ограничение зафиксировано для дальнейшей доработки. Суфлёр зарегистрировал этапы и выполнил проверку установщика, но отклонил отправку снимка на внешнее ревью. Независимые проверки Standards и Spec выполнены отдельно.
