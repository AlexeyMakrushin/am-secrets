# Глоссарий

- **Запись** — элемент Bitwarden, содержащий одно или несколько полей.
- **Поле** — именованное значение внутри записи.
- **Локальное хранилище** — зашифрованная копия выбранных полей, настроенная для конкретного пользователя Mac.
- **Правило выдачи** — связь поля с полными путями программ, которым его можно передать при запуске.
- **Закрытый архив** — прежний приватный репозиторий с историей, обсуждениями и старыми релизами.
- **Кандидат на публикацию** — проверенные исходники, история и архив релиза в новом приватном репозитории.
